# Contributing

Thank you for considering a contribution.

## Good first contributions

- Improve practice descriptions
- Propose new vendor-neutral checks
- Add tests
- Improve CLI output
- Add example assessments
- Improve documentation

## Development

```bash
python -m pip install -e . pytest
pytest -q
```

## Pull requests

Please keep changes focused and explain the problem being solved. New assessment practices should remain vendor-neutral unless they are explicitly added as provider mappings.

By contributing, you agree that your contribution will be licensed under the project's MIT License.

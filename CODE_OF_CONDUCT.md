# Code of Conduct

## Our commitment

We are committed to providing a welcoming, professional, and harassment-free environment for everyone participating in this project.

## Expected behavior

Be respectful, constructive, and focused on the technical merits of ideas and contributions. Give and receive feedback professionally. Respect differing experience levels and perspectives.

## Unacceptable behavior

Harassment, discrimination, personal attacks, threats, doxxing, and deliberately disruptive behavior are not acceptable.

## Reporting

If a problem occurs, please report it privately to the project maintainer through an appropriate contact channel listed on the maintainer's GitHub profile.
